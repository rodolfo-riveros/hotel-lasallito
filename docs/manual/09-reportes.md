# Reportes

Pantalla: **Reportes**. Todos se filtran por fechas y se exportan a **PDF, Excel y CSV**.

| Reporte | Para qué sirve |
| --- | --- |
| Indicadores por día | Ocupación, ADR y RevPAR |
| Ingresos por área | Alojamiento, restaurante, tours y demás |
| Ingresos por canal | Producción de cada canal y agencia |
| Procedencia | Países de los huéspedes |
| Huéspedes en casa / Llegadas / Estado de habitaciones | Operación diaria y contingencia |
| Pronóstico | Ocupación de los próximos 30/60/90 días contra el año anterior |
| MINCETUR | Arribos y pernoctaciones para la estadística mensual |
| Precios sugeridos | Subir o bajar tarifas según la ocupación prevista |
| Consolidado de la cadena | Comparativo entre hoteles y total del grupo |

## Glosario

- **Ocupación:** habitaciones vendidas ÷ disponibles.
- **ADR:** ingreso de alojamiento ÷ habitaciones vendidas (tarifa promedio).
- **RevPAR:** ingreso de alojamiento ÷ habitaciones disponibles.

## Envío programado por correo

**Reportes → Envío programado por correo**: elija el reporte, los correos, la frecuencia y el formato.

- **Diario:** el día anterior.
- **Semanal:** cada lunes, la semana anterior.
- **Mensual:** cada día 1, el mes anterior.

Se envían solos con el programador de tareas.
